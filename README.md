# Gabriel Campos — Portfolio

Site pessoal de Gabriel Campos, publicado com GitHub Pages.

Acesse: https://igabrielcampos.github.io/

## Stack

- Astro (v4)
- TypeScript
- Tailwind CSS
- GitHub Actions (CI/CD)
- GitHub Pages

## Sobre este repositório

Este repositório contém o código-fonte do meu portfólio pessoal e diário técnico de engenharia, com deploy automático via GitHub Actions para o GitHub Pages.

## Desenvolvimento local

```bash
# Clonar o repositório
git clone https://github.com/iGabrielCampos/igabrielcampos.github.io.git
cd igabrielcampos.github.io

# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
